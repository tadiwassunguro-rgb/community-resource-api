# Before publishing to GitHub

1. Read every file and make sure you understand it.
2. Change the README's "Why I built it" section to your own story.
3. Add at least one feature yourself before submitting it.
4. Run the tests with `pytest -q`.
5. Commit your work in small, meaningful commits.
6. Do not describe this as an old project if you created it for this application.
7. If you submit it to MLH, be ready to explain the database design, validation, request flow, logging, health checks, and testing.
